# Chemistry
Name: Natalie Beylin
Project: IHD Calculator
Package Name: IHD
Function: This program takes a formula as a user input, demonstrates the formula
	      for units of hydrogen deficiency, and provides the IHD result.


Installation Instructions:
Java version: 23-09
Open zip file and open Chemistry.java to run it.


Classes that should be in the file:
IHD.java
Run the IHD class


Example #1:
Enter the chemical formula C6H12N

Output:

2 x 6 Carbons + 1 Nitrogens - 12 Hydrogens - 0 Halogens + 2
------------------------------------------------------------
                             2                            

Units of Hydrogen Deficiency: 1

Example #2:
Enter organic formula: C14H20Br2

2 x 14 Carbons + 0 Nitrogens - 20 Hydrogens - 2 Halogens + 2
------------------------------------------------------------
                             2                            

Units of Hydrogen Deficiency: 4

Example #3:

Enter organic formula: C7H14F44

2 x 7 Carbons + 0 Nitrogens - 14 Hydrogens - 44 Halogens + 2
------------------------------------------------------------
                             2                            

INVALID FORMULA: IHD = -21
